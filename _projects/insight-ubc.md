## What it is

This is a course project where students collaborate to construct a
web app that takes in a dataset of UBC course offerings, and provide
useful and valuable insights about these courses through a
user-initiated query process.

## Highlights

- Collaborated with a peer to develop a full-stack web application where users can upload and add, remove existing, list existing UBC’s course section datasets, and perform queries on them in JSON-formatted files compressed as one zip file.
- Combined using chai-as-promised for smoke tests, unit tests, integration tests, and end-to-end tests that ensure the functionality of each data structure and the entire application.
- Utilized Express for the web application’s framework to write RESTful APIs which allow sending requests and receiving responses with proper and reasonable status codes and results or errors.
