Welcome to the blog. This is where I'll write up things I'm learning at the
intersection of **software** and **economics** — project post-mortems, notes on
papers, and the occasional half-formed idea.

## How this works

Each post is a single Markdown file in `_blog/`. To publish a new one, I copy
this file, rename it, edit the front matter (title, date, summary, tags), and
write the body in plain Markdown. It shows up on the [blog index](/blog/)
automatically, newest first.

## What to expect

- Short technical write-ups when I build something.
- Notes connecting economic ideas to systems I work on.
- Links and things worth remembering.
